# Contribution Guidelines

Thank you for your interest in contributing to Hyper Code Editor V2! Here's how you can help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Hyper-Code-Editor-.git`
3. Create a feature branch: `git checkout -b feature/my-feature`
4. Install dependencies: `npm install`
5. Start development: `npm start`

## Code Style

- Use TypeScript for type safety
- Follow React best practices and hooks
- Use functional components
- Add JSDoc comments for complex functions
- Keep components focused and reusable

## Commit Messages

- Use clear, descriptive commit messages
- Start with a verb (Add, Fix, Update, etc.)
- Keep messages under 50 characters
- Example: `Add syntax highlighting for TypeScript`

## Pull Request Process

1. Update README.md with any new features
2. Test your changes thoroughly
3. Ensure TypeScript compilation passes: `npm run type-check`
4. Run linter: `npm run lint`
5. Submit PR with detailed description

## Reporting Bugs

- Use GitHub Issues
- Include reproduction steps
- Attach screenshots if applicable
- Specify OS and version

## Feature Requests

- Describe the use case
- Explain why it would be helpful
- Provide examples if possible
